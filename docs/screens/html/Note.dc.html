Client A Oct 19

The access token is refreshed in middleware, not in the client. The client never sees the refresh token.

Why

Refresh logic lives in one place, and the refresh token can’t leak through browser storage.

Whiteboard after the auth review

Gotcha

Requests sent at the same time can all try to refresh. The middleware queues them behind the first one.

The code is in auth/refresh.ts.
