# Empty state

What a screen shows when it has nothing in it: an empty list, no search results, inbox zero, all done today.

- One short bold line that states the fact ("Nothing yet.", "No matches.", "All sorted."). No illustration needed.
- At most one action under it, as a dashed add action ("+ Add a todo"), never a paragraph.
- A one-time tip (first launch only) is a dark bubble pointing at the control it describes, with "Got it". It never comes back.
