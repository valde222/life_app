# Next card

The dark card for the next thing with a time on Today. There is only ever one.

- `accent` background, `radius-feature` corners, time in `time-large`.
- Shows the start time, the title, how soon, and the end time when there is one ("in 1h 20m, until 13:00").
- On the right: the list label, or an "Event" label with a calendar icon when it is an event. Tapping the card opens the item.
- Later timed things sit below as todo rows (todos, with a checkbox) or event rows (no checkbox).
