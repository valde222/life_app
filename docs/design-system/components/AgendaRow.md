# Agenda row

One thing on a day in Agenda. Agenda is for looking ahead, so rows have no checkbox; tap one to open it.

- Timed: the start time in a 64px column, the end time under it when there is one.
- Untimed: no time column at all, so the title starts at the left edge.
- Events get a grey "Event" label instead of a list label and open Event detail.
- Repeating items sit on a `quiet` row with days since in the time column and no label.
- Day headers are eyebrows ("TODAY, WED 21 OCT"). An empty day is one line with "Nothing planned" on the right, and runs of empty days fold into one ("SUN 25 OCT – MON 26 OCT").
