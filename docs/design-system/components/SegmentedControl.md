# Segmented control

Switches between two views of the same thing: Todo or Note in capture, Todos or Notes in a list.

- Track in `soft`, 4px padding, `radius-control` + 2.
- Selected segment is `surface` with a 1px shadow; others are transparent with `ink-2` text.
- Labels can carry a count right after the word ("Notes 9"). Never more than two or three segments.
