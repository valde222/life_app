# List label

The colored word that says which list a todo or note belongs to.

- Always a word; never a dot or color alone.
- Uses the list's pair of tokens (`life-bg` with `life-fg`, and so on), `label` style, `radius-label`.
- Leave it out where the screen already says the list (inside a list, on a list's own page).
- The same pairs fill the Move to chips in the inbox, at 34px tall.
