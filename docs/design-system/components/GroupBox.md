# Group box

Groups (Life, Work, anything the user makes) on Lists. Closed boxes stack on top of each other; tap one to open it.

- One white card per group, `radius-feature`, 8px apart.
- Header: group name (18/700), a summary on the right, a chevron that turns down when open. Closed: "2 lists, 8 todos". Open: "5 lists".
- Open: its list rows, then "+ New list" at the bottom of the box.
- "+ New group" is a dashed add action under the last box. There are no built-in groups.
- Several boxes can be open at once. The app remembers which.
